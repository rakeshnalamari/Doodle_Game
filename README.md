# Doodle_Game
Doodle Jump is a fun and interactive browser-based 2D platformer game inspired by the classic mobile game. The objective of the game is to guide the player (a cute character) as it jumps from one platform to another, aiming to climb as high as possible without falling.

Programming tools used:
HTML
CSS
JavaSript
GitHub
